# Wolkenkratzer: Shinpan no Tou — English Translation Patch

Fan translation toolchain for the PlayStation 1 JRPG **摩天楼 〜Wolkenkratzer〜
審判の塔** (SLPS-00197, 1996, Asmik/Westone).

The game stores all of its text as uncompressed Shift-JIS and draws every glyph
from the **PlayStation BIOS kanji ROM** — there is no font anywhere on the disc.
This project hooks the rasteriser and injects a custom 5×9 pixel font that packs
**two Latin letters into each 16 px full-width cell**, giving real 8 px-per-
character English without touching the engine's advance, wrapping or primitive
logic. See [`docs/PROJECT_KNOWLEDGE.md`](docs/PROJECT_KNOWLEDGE.md) for the full
reverse-engineering write-up.

Status: **Track A (in-engine text) complete and shipping.** Track B (TIM image
overlays — endings, credits, menus) is complete but its renderer scripts are
partially missing from this repo; see *Known gaps* below.

## Quick start

```bash
pip install -r requirements.txt

# put the pristine Japanese originals in place (see orig/README.md)
cp extracted/MAIN.EXE     orig/MAIN.EXE.bak
cp extracted/SLPS_001.97  orig/SLPS_001.97.bak

./build.sh
```

Outputs `build/MAIN.EXE` and `build/SLPS_001.97`. Drop both into your extracted
disc directory, rebuild with `mkpsxiso rebuild.xml`, and run in an emulator.

The build is **deterministic** — same inputs, same bytes. Reference build from
`script_traduit.ods` as of 2026-08-16:

```
MAIN.EXE       md5 4c2605e3e1a2d58f59d55e45dab40b09   1085440 bytes
SLPS_001.97    md5 97781c0e7602fbbbc178eff81358fa76    333824 bytes
```

`build.sh` runs `tools/verify_build.py` at the end; a good build prints
`ALL PASS`.

## Pipeline

`build.sh` runs four stages. They are separable if you need to debug one:

1. **`script/ods2tsv.py`** — flattens the spreadsheet to TSV.
2. **`tools/build_final3.py`** — the real build. Loads the TSV, applies the
   layout rules (word wrap at 28 half-columns, slot padding, field-group
   padding), pair-encodes ASCII runs into custom codes, packs the glyph atlas,
   assembles the 21-instruction rasteriser hook, relocates every string into the
   vacated pool while rewriting its data pointers and lui/addiu code refs, and
   applies the five status-screen label-x immediates. Writes both executables.
3. **`tools/patch_levelup.py`** — repoints the level-up digit writers at the
   English `XX` placeholder positions.
4. **`tools/patch_dayhour_ui.py`** — translates the day/hour UI, adds the `"D "`
   glyph to a free code slot, and nudges the light-sleep hour-number x.

Steps 3 and 4 are **post-build patchers, not part of the build** — a rebuild
that skips them loses those fixes. Run order between them does not matter; they
touch disjoint regions.

### Editing the translation

Edit `script/script_traduit.ods` and re-run `./build.sh`. The `english` column is
authoritative for everything except a handful of structural strings that
`build_final.py` deliberately shadows (menu command widths, the name-entry letter
grids, the bonus prompt) and the pointer-less in-place strings in
`build_final3.py`'s `TRIMS` — those have hard byte budgets and are overridden in
code. A string that will not fit reports as `skip 0x...: in-place too big` and
must be shortened *there*, not in the spreadsheet.

## Known gaps

- **Track B renderer scripts are missing.** `timtext.py`, `make_english_we.py`
  and `make_english_yesno.py` were delivered in an earlier `english_overlays/`
  output bundle and are not in this repo. The translated `.TIM` files themselves
  are also not here. Recover both from that download and drop them into
  `tools/overlays/` and an `overlays/` asset directory. `timcodec.py` and
  `make_english_ui.py` — the parts that were preserved — are included.
- **The post-build patchers are not folded into `build_final3.py`.** Merging
  them would mean adding the `"D "` glyph to the atlas at build time and moving
  the level-up writer relocation into the allocator. Until then `build.sh` is
  the only correct way to produce a complete binary.
- **No disc-rebuild automation.** `dumpsxiso` / `mkpsxiso` are run by hand.
